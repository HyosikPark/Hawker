# 메인넷 전환 득실 (2026-08-30)

## 결론 먼저
기술·비용은 거의 공짜이고 쉽다. **진짜 결정 변수는 규제 하나** — 그리고 그 답이
우리 두 결제 레일의 운명을 가른다.

## 얻는 것
- **x402 Bazaar 자동 노출** — 에이전트 직접 발견 채널의 나머지 절반. (단 아래 참고: 테스트넷도 인덱싱됨)
- 진짜 USDC 매출. "$100 사냥"의 $가 진짜가 됨.
- "테스트넷이면 가짜" 반박 소멸. gold-402 등 "Base 표준" 디렉토리 등재.

## 비용·난이도 (놀랍게 낮음)
- CDP 계정 무료, API 키 1쌍. facilitator 월 1,000건까지 무료, 초과 건당 $0.001.
- **판매자 가스 부담 0** (facilitator 대납, gasless). 시작 자본금 불필요 — 받기만 함.
- 코드 변경 2~3줄: network eip155:84532→8453, stub 해제, CDP 키 연결.

## ⚠️ 중요 정정: Bazaar 등재에 메인넷이 필수가 아니다
리서치 확인 — CDP discovery는 **테스트넷(Base Sepolia)도 인덱싱**한다. 즉 "발견 채널"만이
목적이면 **CDP facilitator로 바꾸되 테스트넷 유지**로도 Bazaar 등재를 테스트할 수 있다.
메인넷 = "진짜 돈"이 목적일 때만 필요.

## 🚨 규제가 진짜 결정 변수 — 우리 두 레일의 운명이 갈린다
- **x402 직결 레일**: payTo를 **판매자 지갑으로 직접 지정**하면 자금이 판매자에게 바로 감.
  **Hawker는 자금을 보관/수탁하지 않음 = 비수탁(non-custodial) 라우팅** → 규제 노출 크게 낮음. ✅
- **선불 크레딧 레일 (Stripe)**: 구매자 돈을 **Hawker가 먼저 받아 보관 후 판매자에게 지급**.
  = 명백한 자금 보관/이체 구조 → **자금이체업/VASP(특금법) 규제 리스크 훨씬 높음.** 🚨
- **권고**: 메인넷 초기엔 **x402 비수탁 모드만** 켠다. 선불 크레딧(수탁) 레일은 실 USDC/실돈으로
  켜지 말 것 (법률 검토 전까지). "플랫폼이 남의 돈을 보관/라우팅"하는 선이 가장 위험.

## 현금화 (한국 개인) — 기술은 쉬우나 실무 마찰 큼
- Base USDC를 한국 거래소가 입금 크레딧 해주는지 불확실 → 글로벌 거래소(Coinbase/Binance) 경유가 안전.
- 트래블룰(100만원↑), 실명계좌 KYC 필요.
- 세금: 2026 유예, **2027부터 22%**(250만 공제 후). 지금부터 취득가·수취시점 기록 남길 것.

## 비가역 리스크
- 온체인 전송 되돌릴 수 없음. payTo 오타/테스트넷주소 = 자금유실. 시드문구 유출 = 전액도난.
- 서버 지갑에 큰 잔액 두지 말고 콜드지갑 스윕. x402는 검증된 USDC EIP-3009 경로라 컨트랙트 리스크는 낮음.

## 판단 (전략)
현재 우리 구조는 payTo가 **플랫폼 지갑(0x9856...)** = 우리가 일단 받아서 정산하는 **수탁 모델**.
이건 규제상 위험한 쪽. 메인넷 실돈으로 가려면 **아키텍처를 비수탁으로 바꿔야** 함:
상품마다 판매자 지갑주소를 받아 payTo를 판매자로 직결 → 우리는 자금 안 만짐, 수수료만 별도 수취.

**단계적 권고**:
1. 지금: 테스트넷 유지하되 CDP facilitator로 전환 → Bazaar 등재 테스트 (실돈 0, 발견 채널 확보)
2. 신호 확인 후: 비수탁 아키텍처(payTo=판매자)로 리팩터 → 메인넷 x402만 켬
3. 선불 크레딧(수탁) 레일은 법률 검토 전까지 실돈 미가동. 데모/테스트 전용으로.
