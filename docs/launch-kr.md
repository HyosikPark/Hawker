# 한국 커뮤니티 게시 초안 (GeekNews · 디스콰이엇)

> 용도: Show HN 전 리허설 + 국내 기록/평판 쌓기. 서버 복구 후 게시.

## GeekNews (news.hada.io) 초안

**제목:** AI 에이전트에게 한국 데이터를 파는 가게를 만들었습니다 (Hawker)

**본문:**

AI 에이전트가 API를 직접 사서 쓰는 시대가 시작되고 있습니다. Coinbase의 x402(HTTP 402
기반 결제 프로토콜)는 이미 누적 1억 건 이상 처리됐고, Stripe·Visa·Mastercard가 전부
에이전트 결제 레일을 깔고 있습니다.

그런데 한 가지 공백이 보였습니다 — **한국 데이터는 글로벌 에이전트에게 보이지 않는다**는 것.
공공데이터포털에 수만 개의 API가 있지만 한국어 문서, 복잡한 가입 절차, XML 응답 때문에
ChatGPT나 Claude 같은 에이전트가 쓸 방법이 없습니다.

그래서 둘을 만들었습니다:

1. **Hawker** — OpenAPI 스펙을 붙여넣으면 에이전트가 발견·호출·건당결제할 수 있는
   MCP 서버로 만들어주는 게이트웨이. 결제는 x402(USDC, 에이전트 자율)와 선불 크레딧
   (Stripe) 이중 레일. 실패한 콜은 과금 안 함.
2. **한국 데이터 상품들** — 아파트 실거래가(국토부), 사업자등록 상태조회(국세청),
   공휴일(천문연) 등을 에이전트 친화적으로 (XML→JSON 변환, 지역코드 무료 조회 툴 포함).

지금은 Claude Code에 URL 하나 등록하면 "강남 아파트 최근 실거래가 알려줘"라고 물었을 때
에이전트가 $0.005를 내고 국토부 실거래 데이터를 사서 답합니다. 테스트넷이지만 온체인
정산까지 실제로 돌아갑니다 (Base Sepolia 트랜잭션 기록 있음).

기술 스택: TypeScript 모노레포, Hono, Drizzle, Next.js. 코드 전체 공개:
https://github.com/HyosikPark/Hawker

아직 초기라 피드백이 절실합니다. 특히 "내 API도 팔아보고 싶다"는 분이 있다면 온보딩을
같이 해보고 싶습니다.

## 디스콰이엇 초안 (빌드 인 퍼블릭 톤)

**제목:** 이틀 만에 AI 에이전트에게 첫 매출($0.005)을 올린 이야기

**본문:**

"에이전트 경제의 Shopify"라는 컨셉으로 사이드 프로젝트를 시작했습니다.
AI 에이전트가 고객이 되는 시대에, API 가진 개발자가 에이전트에게 데이터를
팔 수 있게 해주는 도구입니다.

타임라인:
- 1일차: 시장 리서치 → 멀티테넌트 MCP 게이트웨이 + 이중 결제(x402/크레딧) + 대시보드
- 2일차: Fly.io/Vercel 배포, 공식 MCP Registry 등재, 테스트넷에서 에이전트가
  사람 개입 없이 USDC $0.005를 내고 서울 날씨를 사감 (첫 매출 🎉)
- 3일차: 전략 전환 — 플랫폼 경쟁 대신 "한국 공공데이터를 글로벌 에이전트에게 파는
  첫 판매자"가 되기로. 강남 실거래가·사업자조회·공휴일 상품화 완료

배운 것:
- 에이전트에겐 "공짜 데이터"도 공짜가 아니다 (검색·파싱에 추론 토큰이 든다).
  깨끗한 JSON 한 방이 $0.002면 사는 게 싸다
- 마이크로페이먼트는 25년간 인간 심리 때문에 실패했는데, 에이전트는 심리가 없다
- 1인 무자본의 무기는 "무한 활주로" — 고정비 월 $5면 VC 태운 경쟁자보다 오래 버틴다

다음 목표: 모르는 사람의 유료 호출 누적 $100.
