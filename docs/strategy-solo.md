> 경쟁: Merit $10M, Arcade $72M, MCPize, Apify, Cloudflare까지 진입한 시장.

## 1. 대원칙 3개

### 원칙 1 — 플랫폼이 되려 하지 말고, 첫 성공한 판매자가 되어라
양면 마켓 콜드스타트는 1인이 못 푼다. 대신 **Hawker 위에서 우리가 직접 장사해서 돈을 번다.**
- 매출이 곧 콜드스타트 해결 (카탈로그가 참)
- "내가 이걸로 월 $X 번다"는 스토리가 무자본 유일의 영업 자산
- Shopify도 아님 — 이건 **초기 아마존**: 자기 물건 팔면서 인프라를 증명한 뒤 남에게 열었다

### 원칙 2 — 자본 싸움이 물리적으로 불가능한 전장을 골라라: 한국 데이터
글로벌 에이전트 경제의 사각지대이자 우리만의 불공정 우위:
- **공공데이터포털(data.go.kr)**: 수만 개 공공 API가 존재하지만 한국어 문서 + 복잡한 가입 + XML 지옥 → 글로벌 에이전트에게 사실상 존재하지 않는 데이터. "지저분한 걸 깨끗하게" 카테고리의 노다지
- 실거래가, 사업자등록 조회, 법령/판례, 병원/약국, 대중교통 실시간 — 전부 ①신선 ②준독점 ③구조화필요 조건 충족
- Merit도 MCPize도 Cloudflare도 **이건 못 하고, 할 이유도 없다** (시장이 그들에겐 너무 작고 우리에겐 충분히 큼)
- 부수 효과: 카카오페이가 x402 레일을 까는 중 → 한국 쪽 생태계가 열릴 때 "국내 유일 선례"가 되어 있음

### 원칙 3 — 유통은 색인과 콘텐츠로 (돈 안 드는 채널만)

**핵심 구분: 상품은 한국산, 손님(결제)은 글로벌.** 한국 사용자조차 글로벌 에이전트
(ChatGPT/Claude)를 쓰므로, 한국 데이터에 대한 수요도 글로벌 레일을 타고 온다.
한국 커뮤니티는 계산대가 아니라 응원석(리허설·판매자 모집·기록)이다.

채널 우선순위:
1. **글로벌 색인** (수요=돈): 공식 MCP Registry(입점 완료), x402 Bazaar/Agent.market,
   AgentCash 디스커버리 — 등록만 하면 지갑 든 에이전트가 오는 무료 진열대
2. **Show HN + 영문 SEO 콘텐츠**: 영어는 Claude가 전담(작성·번역·댓글 초안).
   "MCP 수익화" 검색은 이미 상업 트래픽을 만드는 중
3. **한국 커뮤니티** (GeekNews, 디스콰이엇, OKKY): ①HN 게시 전 리허설
   ②Phase 2 판매자 모집 ③빌드 인 퍼블릭 기록. 모국어라 부담 최소

## 2. 실행 플랜 (90일 × 3)

### Phase 1 (지금~3개월): "한국 데이터 상인"
- [ ] 공공데이터 기반 고품질 상품 5~10개를 우리가 직접 상품화 (아파트 실거래, 사업자 조회, 대중교통 등)
- [ ] wiki-summary처럼 모델이 이미 아는 데이터는 카탈로그에서 제거 (품질 기준 적용)
- [ ] Show HN 게시 (준비 완료 상태) + 빌드 인 퍼블릭 시작
- [ ] AgentCash 디스커버리·Bazaar에 상품 등록 (그들의 VC 돈이 만든 수요에 무임승차)
- **성공 지표: 우리가 모르는 외부 결제자의 유료 호출 누적 $100** — 이 $100이 이 사업 전체의 진실의 순간

### Phase 2 (3~9개월): 스토리로 판매자 모집
- [ ] "혼자서 에이전트에게 데이터 팔아 월 $X" 콘텐츠 → MCP 서버 만든 개발자들(수익화 못 하는 95%) 대상 영업
- [ ] 1단계 경제 대비 기능: 팀 크레딧, 키별 한도, 월 인보이스 (기업 구매 패턴)
- [ ] 한국 개발자 커뮤니티에 한국어 콘텐츠 (국내 인지도 선점)
- **성공 지표: 외부 판매자 10명, 그중 3명이 실매출, MRR $500**

### Phase 3 (9개월~): 국내 생태계 연결
- [ ] 카카오페이 x402 생태계 접촉 — 이때쯤 "국내 유일 에이전트 커머스 실사례"라는 명함이 생겨 인맥 없이도 대화 가능
- [ ] 세금계산서·국내 결제 로컬라이징 (Phase 2 해자 카드 발동)
- [ ] 선택지 열림: 성장 / 소수 인수 제안 / 알짜 부업으로 유지 — 전부 승리 조건

## 3. 하지 않을 것 (무자본 규율)

- ❌ 유료 광고, 컨퍼런스, 영업 채용 — 돈 드는 유통 전부
- ❌ 수요 집계 경쟁 (지갑/마켓 UI로 AgentCash와 정면승부)
- ❌ 기능 경쟁 (Arcade의 엔터프라이즈 기능 따라가기)
- ❌ 메인넷 크립토 운영 리스크 선제 부담 (수요 증명 전까지 테스트넷+크레딧으로 충분)

## 4. 중단/전환 조건 (Kill Criteria — 매몰비용 방지)

- Phase 1 종료 시 외부 유료 호출 $0 → 데이터 상품 가설 재검토 (다른 버티컬 or 피벗)
- Phase 2 종료 시 외부 판매자 0명 → "판매자 도구" 접고 "한국 데이터 API 회사"로 전환 (그동안 만든 상품들이 그대로 자산)
- 주당 10시간이 3개월 연속 못 지켜지면 범위 축소 논의

## 5. 성공의 재정의

a16z 포트폴리오를 이기는 게 목표가 아니다. 1인+무자본의 승리 조건:
1. **월 $2~5K 수익의 자동화된 사업** (한국 직장인 기준 인생이 바뀌는 부업)
2. 또는 시장이 폭발할 때 **"그 자리에 서 있던 유일한 한국인"**으로서의 옵션 (인수·채용·투자 제안)
3. 최악의 경우에도: 에이전트 경제 전 스택을 실전 구축한 포트폴리오 + 축적된 한국 데이터 상품군

무한 활주로 + 커지는 시장 + 아무도 안 서 있는 자리 = 시간이 우리 편인 게임.
