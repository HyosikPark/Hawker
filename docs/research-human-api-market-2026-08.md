# 리서치: 인간 API 판매 시장은 실재하는가 (2026-08-30)

## 핵심 결론 (사업 근본 검증)

**"개인이 마켓플레이스에 API를 올려 되판다"는 모델은 검증된 무덤이다.**
그리고 이 발견은 Hawker의 정당성이 **전적으로 에이전트 경제 베팅에 달려있음**을 확정한다.

## 근거

1. **RapidAPI = 이 모델의 유일한 대형 실험이자 붕괴 사례**
   - 정점(2022): 개발자 300~400만, API 4만 개, $1B 유니콘
   - 2024-11 Nokia에 헐값 자산매각. 인수 시점 사용자 "수천"·API "수백" — 정점 대비 1/1000
   - 사인(死因): 품질관리 부재(커머디티 레드오션), 수수료 인상(20→25%+), 단일장애점,
     그리고 근본 원인 = **판매자·구매자 모두 "직접 거래가 낫다"** → 중개 가치 붕괴

2. **큰 API 시장 숫자에 속지 말 것**: API 관리 시장 $8.8~16B는 전부 Apigee/Kong(엔터프라이즈
   게이트웨이) + Stripe/Twilio(대형 API-first SaaS)의 돈. "개인이 되판다"는 통계에 안 잡히는 미세슬라이스.

3. **인디 API 수익 현실 (power-law, 잔인함)**
   - 인디 제품의 54%가 매출 $0
   - 소득 발생: 니치 B2B로 4~12개월 인내 후 월 $500~3,000 (소수)
   - 상위: AI래퍼/독점데이터로 월 $5,000~10,000+ (극소수)
   - $1M ARR급(SerpApi 등)은 이미 "회사"(직원 35명), 솔로 아님

4. **결정적: 성공한 인간 API 판매자는 마켓플레이스를 안 쓴다.**
   SerpApi·weatherstack·SocialKit 전부 자기 브랜드·자기 유통으로 성공. 인간 판매자에게
   마켓플레이스 순가치가 낮다 = RapidAPI 붕괴의 본질.

## Hawker에 대한 함의 (정직)

- **"인간이 API 판다"가 참이어도 "인간이 Hawker 같은 중개소를 필요로 한다"를 함의하지 않는다.**
- Hawker가 RapidAPI와 다른 유일한 이유 = **새로운 구매자 계층(자율 에이전트)**:
  - 에이전트는 사람처럼 검색·직접계약 못 함 → 프로그래매틱 디스커버리 필요
  - 에이전트는 카드·계정 없음 → 머신 네이티브 결제(x402/크레딧) 필요
  - 이 둘이 RapidAPI 시대엔 없던 신규 가치
- **결론: Hawker의 존재이유는 판매자(인간) 측이 아니라 구매자(에이전트) 측에 있다.**
  회사 명운은 "자율 에이전트가 유료 API를 프로그래매틱하게 사는 유동성이 언제 생기나"에 달림.
  인간 공급은 조연.

## 전략 교정

1. "누구나 API로 돈 번다" 서사 버릴 것 (54% $0, RapidAPI 트라우마 자극).
2. 공급 진입점을 **"이미 API로 돈 버는 니치 승자"**(스크래핑·데이터·AI래퍼)로 좁힐 것.
   "0→1 창작자"가 아니라 "1→n 유통 확장(에이전트라는 새 채널)"으로 팔 것.
3. 생사 검증 질문: **에이전트 결제 유동성이 언제 얼마나 생기나.** 여기에 전부 걸려있음.

## 우리 리서치들의 일관된 그림 (누적)
- 결제 레일: 풀렸음(레드오션)
- 신뢰/평판: 실측 이행평판이 유일한 빈자리(우리가 쥠), 창 6~12개월
- 정확한 포지션 조합: 아직 아무도 안 함(이중레일+셀프서브+실측평판)
- **인간 API 판매 수요: 얇고, 마켓플레이스는 무덤 → 전부 에이전트 베팅에 의존**
