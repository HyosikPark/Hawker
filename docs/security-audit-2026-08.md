# 남용·안정성 감사 (2026-08-30)

판매자/구매자 악용 관점 코드 감사. 게시 전 Top 5를 수정한다.

## 잘 되어 있던 것
- 결제 무료취득 차단: authorize→upstream→commit, 실패 시 무과금·무데이터 (mcp.ts)
- 크레딧 원자적 차감(경합·음수 방지) (payments.ts)
- 업스트림 키 AES-256-GCM 암호화, 구매자 미노출 (crypto.ts, upstream.ts)
- 배치 요청 거부 (mcp.ts)

## 게시 전 반드시 막을 것 — Top 5 (이번에 수정)
1. **툴콜 레이트리밋 부재** — `/mcp/:slug` 무제한 호출로 DoS 증폭. IP당 리밋 추가.
2. **SSRF 우회** — 리다이렉트 추종·DNS 리바인딩·호출시점 미검사. fetch redirect:manual + 호출 시점 재검사.
3. **priceOverrides 가격 경계 우회** — 음수/초대형 가격. default와 동일 범위검사.
4. **응답 크기 무제한** — 대용량 응답 메모리 고갈. 바이트 상한.
5. **툴 설명 프롬프트 인젝션·무제한 길이** — 구매 에이전트 하이재킹. 길이 상한 + 제어문자 정리.
