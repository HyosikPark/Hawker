## 2. 경쟁 지도 — 레이어별 선점, 통합 상품은 공석

**직접 경쟁 3곳:**
1. **Apify** — 발견+호스팅+건당과금+정산 전부 실전 운영. 개발자 월 $1.2M 지급(누적 $4M+, 80/20 배분). 유일한 약점: 웹 스크레이핑 브랜드에 고정.
2. **Arcade.dev (+Smithery 인수, 2026-08)** — $72M 자본, 최대 MCP 레지스트리 흡수. 단 방향은 "기업 통제"이지 판매자 수익화 아님. 과금 붙이면 즉시 정면 경쟁.
3. **Coinbase x402 Bazaar / Agent.market** — 발견+결제 디렉토리. 크립토 온리, 저단가, 수요 부족이 한계이자 우리와의 간극.

**아무도 안 하는 것 (기회):**
- 법정화폐 네이티브 "발견+호스팅+과금" 통합 (Apify 제외 전무, Apify는 카테고리 갇힘)
- **비개발자/기존 SaaS용 셀프서브 온보딩** — "API 키/스펙 붙이면 MCP화+가격표+결제+배포까지" (전원 개발자 대상만 함)
- B2B 결제 현실: 세금계산서/VAT, 인보이스, 팀 크레딧, 사용량 상한
- 품질·신뢰 큐레이션 (레지스트리 6.7만 개 서버 중 87%가 신뢰 임계 미달)
- 아시아/한국 시장 (전 플레이어 미국 중심)

**경고 사례:** RapidAPI — $1B 밸류에이션 → 직원 82% 해고 → 2024 Nokia 자산매각. "수요 없는 공급자 마켓"의 선례.
**실행 유예 기간 체감 12~18개월** (Arcade-Smithery 인수 = 통합 국면 개시 신호).

## 3. 수요 검증 — 오늘 팔리는 고통 vs 아직 이른 것

**실재하는 고통 (오늘 팔림):**
1. **공급자 수익화 공백** — MCP 서버 6.7만 개 중 유의미하게 과금하는 곳 한 자릿수 %. "거의 아무도 한 푼도 못 벌며 호스팅·유지보수 비용만 흡수." Apify의 월 $1.2M 지급이 반례 = 배분·미터링·정산을 대신해주면 공급자가 몰린다는 증거.
2. **빌더의 조달 마찰** — "수십 개 서비스의 계정·API키·빌링 관리." 필요한 건 한도·화이트리스트·감사로그·단일 인보이스. ("I just want my agent to spend a limited amount of money, just like a human agent can" — HN)
3. **신뢰·품질·분쟁 공백** — 결제 레일은 상품화 끝나가는데 큐레이션+품질보증+환불·분쟁 처리는 무주공산.

**아직 이른 것:** GMV 수수료 모델 (12~24개월 이름). 에이전트가 실제 쓰는 돈이 아직 작음.

**한국:** 카카오페이가 x402 재단 창립 멤버(국내 유일). 레일은 깔리는데 **국산 MCP 수익화 플랫폼/마켓 전무 = 완전 공백**. 국내 커머스(쿠팡·네이버)는 외부 에이전트에 방어적.

## 4. 전략적 결론

- **"골드러시 직전의 곡괭이 장사" 타이밍.** 거래액 기반 사업은 이르지만, 공급자 온보딩 도구와 빌더 조달 도구는 오늘 팔리는 고통.
- **마켓플레이스가 아니라 도구로 포지셔닝** — Shopify가 이긴 방식. 수요 집계(RapidAPI 실패 지점)를 우리가 떠안지 말고, 판매 채널은 기존 레지스트리(공식 MCP Registry, x402 Bazaar, Agent.market, Claude/ChatGPT 디렉토리)에 멀티채널 배포로 올라탄다.
- **결제는 이중 레일** — Stripe(법정화폐, B2B 회계) + x402(에이전트 자율 결제) 동시 수취.
- **한국 = 지리적 해자 옵션** — 세금계산서/국내 결제 대응 + 카카오페이 x402 생태계 연결.
