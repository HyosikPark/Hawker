# 제품 정의 (v0.1 초안, 2026-08-28)

## 비전

**"당신의 API를 5분 만에 에이전트가 사고 쓰는 상품으로."**

에이전트 경제의 Shopify. 우리는 마켓플레이스(수요 집계)가 아니라 **판매자의 도구**다.
수요는 기존 채널(공식 MCP Registry, x402 Bazaar, Agent.market, Claude/ChatGPT 디렉토리)에
멀티채널 배포로 올라탄다 — Shopify가 아마존·인스타그램을 판매 채널로 연결하듯.

## 타깃 사용자 (1차)

- 이미 API/데이터/서비스를 가진 개발자·소규모 팀 (글로벌, 영어권 우선)
- MCP 서버를 만들었지만 수익화 못 하는 6.7만 서버의 주인들
- "과금 시스템 만드는 데 수 주가 걸린다"는 그 고통을 5분으로 줄여준다

## 사용자 여정 (MVP)

1. **연결** — OpenAPI 스펙(URL/붙여넣기) 또는 기존 MCP 서버 URL 제출.
   업스트림 API 키는 암호화 볼트에 저장(구매자에게 절대 노출 안 됨).
2. **상품화** — 노출할 툴 선택, 설명은 LLM이 에이전트 친화적으로 다듬어줌. 툴별 가격 설정(건당 USD).
3. **호스팅** — `{slug}.우리도메인/mcp` 로 멀티테넌트 원격 MCP 서버(Streamable HTTP) 즉시 발급.
4. **과금 (이중 레일)**
   - **x402**: 에이전트가 인간 개입 없이 USDC(Base)로 건당 결제 — 오늘 동작하는 유일한 자율 결제 경로
   - **선불 크레딧**: 인간 개발자가 Stripe로 크레딧 구매 → API 키 발급 → 건당 차감 (법정화폐·B2B 경로)
5. **배포** — 공식 MCP Registry + x402 Bazaar 자동 등록, 에이전트가 읽을 수 있는 상품 랜딩 페이지 자동 생성.
6. **정산** — 대시보드(호출 수·매출·에러), 판매자 지갑/계좌로 주기 정산. 수수료 10~15%.

## MVP 범위에서 뺀 것 (Non-goals, v0.1)

- 자체 마켓플레이스 UI·리뷰·랭킹 (수요 집계는 남의 채널에 맡긴다)
- AP2/카드 네트워크 연동 (스펙 호환만 염두, 6~12개월 뒤)
- SLA 보증·분쟁 처리 자동화 (수동으로 시작)
- 한국 로컬라이징: 세금계산서·국내 결제·카카오페이 x402 (Phase 2 — 지리적 해자 카드로 보관)
- 비개발자 온보딩 (Phase 2 — "Zapier 계정 연결하면 상품화" 같은)

## 수익 모델

- 거래 수수료 10~15% (Apify 20%, 신생 경쟁자들 10~20% 사이 — 초기엔 10%로 공격적으로)
- 판매자 등록·호스팅 무료 (공급 확보가 우선)
- 추후: 프로 티어(커스텀 도메인, 고급 분석, 낮은 수수료)

## 경쟁 차별점 (리서치 근거)

| 그들 | 우리 |
|---|---|
| Apify — 스크레이핑 카테고리에 갇힘 | 임의의 API/서비스 범용 |
| Coinbase Bazaar — 크립토 온리 | 이중 레일 (법정화폐 + 크립토) |
| Arcade/Smithery — 기업이 툴을 "쓰게" 함 | 판매자가 툴을 "팔게" 함 |
| MCPay/xpay 등 페이월 미들웨어 — 과금만 | 상품화+호스팅+과금+배포 통합 |

## 콜드스타트 전략

1. 우리가 직접 유용한 유료 툴 3~5개를 첫 상품으로 등록 (도그푸딩 + 카탈로그 초석)
2. r/mcp, HN, MCP 커뮤니티에서 "수익화 못 하는 서버 주인" 직접 온보딩 (수요 리서치에서 확인된 그 사람들)
3. "Show HN: Turn your API into an agent-payable product in 5 minutes" 런칭

## 성공 지표 (첫 90일)

- 등록 판매자 30명 / 라이브 상품 50개
- 외부 에이전트의 유료 호출 발생 (단 1건이라도 — 자율 결제 루프 증명)
- 첫 판매자 정산 실행
